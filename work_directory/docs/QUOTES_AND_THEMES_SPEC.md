# StopScroll — Dynamic Landing Page & Quotes Specification

This document details the redesigned **Full-Screen Blocked Page Architecture**, the **Dynamic Quotes Catalog**, and the **Atmospheric Visual Themes** designed to make every blocked visit inspiring, dynamic, and effective.

---

## 1. Problem & Design Goals

### The Problem
1. **Visual Fatigue**: Static, repetitive block screens become white noise that users instinctively close or bypass.
2. **Lack of Emotional Reset**: Distraction triggers (boredom, anxiety, dopamine craving) need a psychological pattern interrupt, not just a technical wall.
3. **Low-Resolution Extension Bar Icon**: The previous icon was a pixelated raster buffer without subpixel antialiasing or high-DPI scaling.

### The Solution
1. **Crisp 4x-Supersampled Vector Icon**: Clean rounded modern shield with high-contrast checkmark and rose-to-amber brand gradient.
2. **Full-Screen Immersive Canvas**: Full viewport coverage with big, bold, cinematic typography.
3. **Non-Repeating Combinatorial Engine**: Pairs 6 distinct visual moods with 50+ curated high-voltage quotes, rotating on every visit.

---

## 2. Four Template Archetypes

| Archetype | Mood & Visuals | Best For |
|:---|:---|:---|
| **1. Cinematic Horizons** | Dark alpine vistas, moody coastal twilight, deep cosmic stars with soft vignette | Stoic & philosophical reflections |
| **2. Bold Brutalist** | High-contrast carbon matte `#050507`, massive uppercase sans-serif (`font-black`), glowing neon amber highlights | Direct dopamine snap & raw discipline |
| **3. Zen Breath** | Ambient liquid aurora gradient mesh with animated rhythmic breathing ring | Anxiety relief & calming autopilot urges |
| **4. Modern Editorial** | Clean Swiss / editorial layout with category tags (`#DEEP_WORK`), styled quotes, and author attribution | Knowledge workers & creative focus |

## 4. Technical Implementation Plan for StopScroll

1. **Pre-bundled Background Assets & Themes**:
   - Packaged in `extension/assets/themes/` with CSS mesh gradients, subtle SVG pattern overlays, and lightweight vector assets so the page loads under 10ms with zero network requests.
2. **Quote Engine Module (`extension/shared/quotes.js`)**:
   - Exports the structured 50-quote library with tags and categories.
3. **Dynamic Generator in `blocked.js`**:
   - Reads `sessionStorage` or local memory to ensure sequential/weighted randomization (no immediate repeats of the same theme or quote).
   - Generates random combinations of:
     - `theme`: 1 of 4 archetypes (Cinematic, Brutalist, Zen, Editorial).
     - `quote`: 1 of 50 quotes matching the tone.
     - `background`: CSS ambient aura / gradient wash.
   - Interactive keyboard shortcut: `Spacebar` or `R` triggers a silky instant crossfade to a new quote.
4. **Toolbar Icon Upgrade**:
   - Deploy the new 4x-supersampled, antialiased, vibrant gradient shield icon across 16x16, 32x32, 48x48, and 128x128.
