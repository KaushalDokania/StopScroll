Rule Resolution Priority

How StopScroll handles overlaps between the Hard Blocklist and Timer Allowances.

1

Priority 1: Hard Blocklist (Top Precedence)

If a site is on the Hard Blocklist, it is always blocked immediately. Any timer configured for it is superseded.

2

Priority 2: Timer Group Allowance

If the site is NOT on the hard blocklist, its Timer Group is checked. If the group has minutes remaining, access is granted and time decrements. If the timer hits 0:00, access is blocked.

3

Priority 3: General Browsing (Allowed)

If a site belongs to neither list, it loads without restriction.
